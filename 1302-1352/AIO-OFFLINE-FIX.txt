AIO OFFLINE FIX — PS4 13.02–13.52

Fixed:
- Firmware minor version parsing in ps4_offsets.js: decimal parsing is used.
  The old code parsed the minor part as hexadecimal, so 13.52 could become
  13.82 and fail to select the local offset table.
- Offline Application Cache manifest version was bumped to invalidate the
  previous cached copy.
- jb.js prints the detected User-Agent when firmware lookup fails.

Local mappings already present:
13.02 -> 1302.bin + payload2.bin
13.04 -> 1302.bin + payload2.bin
13.50 -> 1350.bin + payload2.bin
13.52 -> 1352.bin + payload2.bin

Exploit primitives, firmware offsets, patch blobs and payload bytes were not
modified by this AIO fix.
